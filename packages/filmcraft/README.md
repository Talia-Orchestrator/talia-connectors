# filmcraft MCP preset

Declarative configuration for the official filmcraft MCP integration. The package stores a generic executable hint and optional path-field definitions only. It does not include or execute the external application, MCP server, credentials, or machine-specific paths. Users install the preset, then configure and connect it explicitly in Talia.
